01 Why Knowledge Alone Fades

なぜノウハウ発信だけでは埋もれるのか
— ファン化の原理

この章でわかること ファンが生まれる仕組み
CORE MESSAGE

ノウハウは検索で代わりがきます。でも「人」は代わりがききません。

毎日投稿しても数字が動かない。原因は努力の量ではありません。

情報は代わりがきく。人はきかない。

同じ話をもっと上手にまとめる人は、必ず現れます。

ノウハウ発信、3つの限界

ノウハウ「だけ」が苦しいのです。

フォロワーとファンは、別のもの

数字は同じ「1」でも、中身は別ものです。

1万人のフォロワーより、100人のファン

売上を決めるのはファン率と値段です。

ACTION 今日やること
  • 直近10投稿を「情報だけ」と「あなた入り」に仕分けます。
  • 保存・DM・返信をくれた人を数えます。
  • 追う数字を「数」から「率」に変えます。

できていなくて当然です。気づけたら半分進んでいます。

02 The Three Layers of You

あなたらしさの正体
— 3つの層でできている

この章でわかること あなたらしさの出し方
CORE MESSAGE

あなたらしさは才能ではなく作り方です。

あなたらしさ（＝属人性）＝その人でないと成り立たない部分のことです。

「出せるものがない」と感じても大丈夫。まだ書き出していないだけです。

いちばん効くのは、奥の「価値観」

比率は「ノウハウ6：らしさ4」

混ぜるから効きます。数字はあくまで目安です。

出すものがないなら、書き出す15問

思いつかなくて当たり前です。

全部を見せる必要はありません

どこまで見せるかは、自分で決めていいのです。

ACTION 今日やること
  • 15問のうち、答えやすい5問だけ今日埋めます。
  • いちばん話しやすい答えを1つ丸で囲みます。
  • 「これは出さない」と決めた線を1行メモします。

1問書けたら、それが最初の素材です。

03 Empathy By Everyday

「好き」で共感を生む
— 日常の出し方

この章でわかること 日常が共感に変わる書き方
CORE MESSAGE

人は「同じものが好き」な相手に心を開きます。

似ているほど好きになる（＝類似性の法則）。共通点は実績でなくて大丈夫です。

ネタ選びで迷ったら、この7つから選びます。

日記との分かれ道は「ひと言」

出来事だけなら日記です。理由をひと言足すと、共感に変わります。

ひと言の足し方は、たった3語

同じネタで比べてみましょう

回数の決め方 — 1日2〜5本

出来ばえより「毎日いること」が効きます。

会う回数が、近さを決めます

ACTION 今日やること
  • 日常ネタ7選から1つ選び、ストーリーズを1本出します。
  • その1本に「なぜそうしているか」をひと言つけます。
  • 明日の朝に出すネタを、今のうちに決めます。

あなたの言葉のほうが届きます。

04 Scars Become Assets

マイナスのストーリーが
最強の武器になる理由

この章でわかること 弱さを強みに変える順番
CORE MESSAGE

完璧な人は憧れられますが、弱さを見せた人は愛されます。

届くのはいつもうまくいかなかった話です。

先に開くと返ってくる（＝自己開示の返報性）。

V字の語り方 — どん底・転機・今

この3つだけで物語になります。締めは「まだ道の途中」です。

出せるマイナスは、この4か所

出す前の安全装置

出すのは乗り越えた過去だけです。

ACTION 今日やること
  • 第2章の「過去5問」から、語れる挫折を1つ選びます。
  • どん底・転機・今の3行で、V字の下書きを書きます。
  • 最後の1行を「まだ道の途中です」に書き換えます。

出しにくいなら、まだ早いサインです。

05 Show The Future

理想の未来を見せる
— 旅とノマドが「憧れ」を作る

この章でわかること 憧れを自慢にしない見せ方
CORE MESSAGE

共感だけでは、買うところまで届きません。「この人みたいになりたい」が行動を生みます。

共感は距離を縮め、憧れは引き上げます。

憧れ発信の型は、この4つ

場所と時間の自由が写る瞬間を切り取るだけです。

自慢に見えない見せ方 3原則

なお、成果の出方や時期には個人差があります。できたことを正直に書きます。

憧れ：共感 ＝ 2：8 が目安

土台は共感です。憧れはときどきで足ります。

人が買うのは「その先の生活」

ゴールが見えない相手は、動けません。

ACTION 今日やること
  • 直近1か月の投稿を、共感と憧れに仕分けて数えます。
  • 憧れの投稿を1本、「過去の自分との差」で書き直します。
  • 商品の先にある「生活」を1文で書きます。

「昨日より少し先」で十分伝わります。

06 Reels × Stories

ストーリーズ×リール
二刀流の使い方

この章でわかること 毎週まわる運用の型
CORE MESSAGE

リールで出会い、ストーリーズで恋に落ちる。

役割がまったく違います。

ファン化の道すじ

ファンは決まった順番で階段を上がってきます。

1週間の予定表（例）

先に枠を決めるのが目的です。

やりとりは「参加を軽くする道具」

アンケートも質問箱も、遊びではありません。

反応した人を、DMへつなぎます

総まとめ — ファン化の設計図

迷ったら、この1枚に戻ってきてください。

ACTION 今日やること
  • 今週の曜日枠を決めて、メモに書き込みます。
  • 今日のストーリーズに、アンケートを1つ入れます。
  • 反応をくれた人に、DMでひと言お礼を送ります。

1つ選んで、今日のうちに終わらせます。
